Code Relay

Run the Code Relay server locally, then open the live event interface.

01
CLONE

Clone the project

git clone https://github.com/auroreRakoto/code-relay.git
cd code-relay
02
INSTALL

Install dependencies

uv sync
03
START

Start the server

uv run python server.py

Keep this terminal open while the event is running.

READY

Open Code Relay

Once the server is running, open the local interface.

Open Code Relay →

The live scoreboard, grading system and relay controls run locally through the Flask server.
